## 🎨 UI/UX Features & Design System

- **Glassmorphism Aesthetics**: Modern backdrop-filter blur effects with dark theme CSS custom properties (`#080C14`, `#0F172A`).
- **Responsive Layout**: Fluid CSS Grid & Flexbox breakpoints for desktop, tablet, and mobile views.
- **Conversion-Optimized CTA**: High-contrast typography hierarchy and glowing CTA buttons.
