---

## ⚡ LMS Engine Features

- **Automated Student Enrollment**: Automatically enrolls students into academy courses immediately upon WooCommerce order payment.
- **Subscription Billing Hook**: Seamless integration with WooCommerce Subscriptions for recurring monthly/annual course memberships.
- **Custom Post Types**: Native `academy_course` and `academy_lesson` Custom Post Types with REST API support.
- **Dynamic PDF Certificate Generator**: Generates verifiable PDF certificates for students upon course completion.
