## ⚡ Features & Performance Architecture

- **Asset Dequeuer**: Automatically dequeues heavy WooCommerce scripts & styles on non-shop pages to improve Core Web Vitals (LCP & INP).
- **Deferred Script Loading**: Adds `defer` attributes to non-critical WooCommerce scripts for sub-second page rendering.
- **Fast Ajax Checkout Engine**: Bypasses full page reloads by processing cart additions via lightweight Ajax endpoints.
- **Automated DB Cleanup**: Daily cron cleanup for expired WooCommerce transients to keep MySQL database tables lightweight.
