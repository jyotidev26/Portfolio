## ⚡ Theme Architecture & Performance Features

- **OOP Architecture**: Object-Oriented PHP 8+ modular classes for custom post types and theme optimization hooks.
- **Custom Post Types**: Native `portfolio` and `service` Custom Post Types registered with REST API support.
- **Speed Engineering**: Automatic dequeuing of WordPress emoji scripts, wp-embed bloat, and inline style rendering.
- **Elementor Pro Ready**: Full compatibility with Elementor Pro theme builder headers, footers, and archive layouts.
