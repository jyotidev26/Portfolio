## 🛡️ Security Features & Engine Architecture

- **Web Application Firewall (WAF)**: Real-time inspection of `$_GET`, `$_POST`, `$_COOKIE`, and `$_SERVER['REQUEST_URI']` payloads against blacklisted attack patterns.
- **SQL Injection Shield**: Instant blocking of SQL command injection attempts (`UNION SELECT`, `DROP TABLE`, `EXEC`).
- **XSS & Remote Code Execution Filter**: Neutralizes cross-site scripting (`<script>`, `onload=`) and malicious PHP shell executions (`eval()`, `base64_decode()`).
- **File Integrity & Malware Scanner**: Recursive AST and regex file iterator detecting backdoor web shells and obfuscated PHP payloads.
- **IP Rate Limiter**: Session-backed rate limiting to defend against brute-force DDoS attacks (429 Too Many Requests).
