---

## 🚀 Key Modules & Features

- 👨‍🎓 **Student Admission & Profile Management**: Complete record-keeping for students, guardians, and academic history.
- 📊 **GPA & Result Processing Engine**: Automated GPA calculation based on standardized grading scales.
- 📋 **Daily Attendance Tracker**: Real-time attendance percentage calculator and reporting.
- 💳 **Fee Collection & Receipt Generation**: Online and manual fee tracking with instant digital receipts.

---

## 🛠️ Tech Stack

- **Backend**: OOP PHP 8.0+ & PDO Prepared Statements (SQL Injection Shielded)
- **Frontend**: HTML5, Modern CSS3 Grid & Flexbox, JavaScript
- **Database**: MySQL / MariaDB Relational Schema
